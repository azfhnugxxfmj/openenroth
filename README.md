## Overview

OpenEnroth is a fully open-source reimplementation of the Might and Magic VI, VII, and VIII game engines, enabling these classic late-1990s RPGs to run natively on modern Windows, Linux, and macOS without DOSBox. Built from the ground up in C++, it fixes hundreds of long-standing engine bugs, adds widescreen and any-resolution support, and exposes a Lua modding API while remaining fully data-compatible with original game installations. The project is actively maintained and welcomes community contributions to the open-source engine.

Whether you're a newcomer just getting started or a seasoned pro looking for advanced tools, **OpenEnroth** delivers the features you need in a clean, intuitive package.

## Key Features

| Feature | Description |
|---------|-------------|
| **Native Modern OS** | Runs natively on Windows, Linux, and macOS — no DOSBox required |
| **Widescreen Support** | Any-resolution widescreen rendering with correct aspect-ratio HUD scaling |
| **Bug Fixes** | Hundreds of original Might & Magic engine bugs corrected from source |
| **Lua Modding API** | Exposed Lua scripting hooks for game mechanics, items, and level content |
